# 🎬 SSANGYONG CINEMA: 영화 예매 플랫폼
"데이터 중심의 스마트한 영화 예매 경험을 제공합니다."

## 📌 프로젝트 개요
사용자가 영화 정보를 실시간으로 확인하고, 원하는 좌석을 선택하여 예매하며, 관련 상품까지 구매할 수 있는 통합 영화 예매 서비스입니다. 공공 데이터를 활용한 실시간 예매 순위 정보와 사용자 친화적인 UI/UX를 결합하여 설계했습니다.

## 🛠️ 기술 스택
- **Backend:** Java (JDK 17), Spring Boot, MyBatis
- **Database:** Oracle Database (SQL Developer)
- **Frontend:** HTML5, CSS3, JavaScript (AJAX)
- **Open API:** 영화진흥위원회(KOFIC) 카카오페이(KAKAO PAY) API
- **Tool:** Git, GitHub

## 📊 서비스 구조 (ERD)
![구조도_이미지_경로](./images/erd_diagram.png)
*회원(Member)을 중심으로 예매(Booking), 영화(Movie), 상영시간(Time), 좌석(Seats) 테이블을 연관시켜 데이터 무결성을 고려한 관계형 데이터베이스를 설계했습니다.*

---

## 🚀 주요 기능 및 기술 구현

### 1. 영화 정보 API 연동 (메인 화면)
- **실시간 데이터 활용:** 영화진흥위원회 오픈 API를 호출하여 최신 예매 순위를 동적으로 받아와 메인 화면에 출력했습니다.
- **데이터 파싱:** 외부 API에서 전달받은 JSON 데이터를 Java 객체로 매핑하여 서비스의 신뢰도를 높였습니다.

### 2. 동적 좌석 선택 시스템 (예매)
- **상태 관리:** 예매된 좌석은 회색(비활성화), 선택한 좌석은 빨간색으로 처리하여 사용자에게 직관적인 시각 정보를 제공합니다.
- **예약 로직:** DB의 좌석 정보를 실시간으로 조회하여 좌석 점유 상태를 정확히 반영하도록 설계했습니다.

### 3. 회원가입 및 사용자 편의성
- **비동기 통신 (AJAX):** 회원가입 시 아이디 중복 체크 등을 페이지 새로고침 없이 비동기로 처리하여 사용자 경험(UX)을 개선했습니다.
- **주소 검색 API:** 도로명 주소 API를 연동하여 회원가입 프로세스의 속도와 정확성을 높였습니다.

### 4. 스토어 및 리뷰/평점 시스템
- **스토어 장바구니:** 상품 수량에 따라 총 금액이 실시간으로 계산되는 동적 장바구니 로직을 구현했습니다.
- 
- **리뷰 및 평점 시스템:**
- **개인화 데이터:** 마이페이지에서 사용자가 작성한 리뷰와 별점 정보를 리스트로 조회하고 관리할 수 있습니다.
- **콘텐츠 데이터 공유:** 영화 상세 페이지 진입 시, 해당 영화를 관람한 사용자들의 리뷰와 별점 데이터를 매핑하여 보여줌으로써 사용자 간 실시간 정보 공유 기능을 구현했습니다.

## 💡 기술적 고민 및 배운 점

### 1. 외부 API 활용 능력
- 외부 데이터(영화 정보)를 가져올 때 발생하는 네트워크 지연이나 데이터 포맷 변경에 대응하며, 예외 처리(의 중요성을 체감했습니다.

### 2. 프론트-백엔드 데이터 인터페이스 설계
- 단순히 DB의 데이터를 보여주는 것을 넘어, 사용자가 좌석을 클릭할 때 어떤 데이터를 서버로 보낼지, 서버는 어떻게 응답할지를 설계하며 **RESTFUL한 데이터 교환 방식**을 깊이 있게 이해했습니다.
